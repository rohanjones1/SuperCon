# 16-hour plan (hard deadline). Cut-lines are mandatory.

Principle: get an **end-to-end thin loop** running by hour 8, then deepen. Evidence quality beats feature count.

| Hours | Goal | Exit check |
|---|---|---|
| 0-1 | **De-risk**: install Omnigent; hello-world agent calling one function tool; MP API key works; CHGNet loads and predicts on one structure; repo + ledger skeleton | All four smoke tests pass, or the failing one is logged in DECISIONS.md with a fallback |
| 1-3 | **Data + prereg**: pull seeds/decoys (MP/JARVIS/3DSC), family-level holdout split, control set, write and hash prereg | Split file + prereg hash in ledger; no holdout family in any training data |
| 3-6 | **Deterministic core** (`lab/`): relax, E_hull, novelty, controls, baselines B0/B1, metrics, ledger, batch CLI. Calibration set (candidates that match existing MP compounds) | CLI runs a 100-candidate batch with controls; stability precision/recall vs DFT printed |
| 6-8 | **Thin agent loop**: PI + Hypothesis + Runner + Analyst via Omnigent, calling `tools_api` (batch/ID based) | One full iteration end-to-end in an Omnigent session, logged to ledger |
| 8-11 | **Intelligence**: Planner with 2+ tests and budget; strategy rules; Auditor (different vendor); approval policy; Tc proxy (stretch) | Iteration 2 batch visibly differs due to a rule; approval card appears; auditor can veto |
| 11-13 | **Experiment run**: matched-budget agentic vs B0/B1, 3+ iterations, seeds fixed; timing captured | Results table + CIs generated from ledger |
| 13-14.5 | **Report + figures**: funnel, hit-rate vs iteration, cost per validated hit, limitations, next experiment | Report generated by script; every number has a run ID |
| 14.5-16 | **Demo (2 min) + submission + buffer** | Video recorded, repo README reproduces headline result, submitted with 30 min slack |

## Cut-lines (apply without debate)
- Behind at hour 6: drop phonon and Tc proxy entirely. Rank on E_hull plus a simple heuristic; keep controls and baselines.
- Behind at hour 8: replace parallel sub-agents with sequential; drop strategy-rule UI polish, keep the rule table.
- Behind at hour 11: skip the Planner's 4-test menu; keep exactly two tests (A: E_hull, B: A + extra check) and a visible choice.
- Never cut: ledger, controls, prereg, matched-budget baseline, approval gate, honest limitations.

## Hour-0 smoke tests (do these first)
1. `omnigent` starts; a trivial YAML agent calls a `type: function` tool and returns its result.
2. `MP_API_KEY` fetches one structure via `mp-api`.
3. CHGNet predicts and relaxes one structure on this machine (note seconds per structure).
4. SQLite ledger creates, inserts, and reads back a run record.
